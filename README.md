p# Software Engineering Course Design Project

## Installation and running

- Fetch project codes

```bash
git clone https://github.com/RW-Pyrojewel/SECD-frontend.git
```

- Install dependencies

```bash
cd SECD-frontend

pnpm install

```

- Run

```bash
pnpm dev
```

- Build

```bash
pnpm build
```
